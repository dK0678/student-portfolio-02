DALISO KAFUNDA — INTERACTIVE PORTFOLIO

Open index.html in a modern browser to preview the site. It uses HTML, CSS, and vanilla JavaScript only; no framework or build step is required.

Included interactions:
- Responsive mobile navigation
- Scroll reveal and reading-progress line
- Active navigation state while scrolling
- Click-to-expand photo gallery with keyboard navigation (Escape / arrow keys)
- Video preview play button and animated audio visualizer
- Contact form that builds a prefilled email draft
- Reduced-motion accessibility support

IMPORTANT BEFORE PUBLISHING
The contact email is currently daliso@example.com as a placeholder. Replace it in index.html and in js/main.js with the email address you want people to use. The contact form uses mailto, so it opens the visitor's email app; it does not send messages through a server.

Fonts are loaded from Google Fonts when internet access is available; the site has a sans-serif fallback.
